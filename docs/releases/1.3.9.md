# Music Bank 1.3.9 · Android build 23

Scarica **MusicBank-1.3.9-build23.apk** dagli Assets della release pubblica. Richiede
Android 7 / API 24 o superiore.

## Novità

- “Le mie playlist” parte vuota e contiene soltanto playlist create dall'app.
- Gli ID personali sono separati per server/account e salvati senza credenziali.
- Le raccolte che coincidono con un album completo vengono riconosciute e nascoste.
- Le playlist reali importate o condivise restano nella sezione server.
- Il controllo aggiornamenti pubblici non richiede più un token GitHub.

## Verifiche

- TypeScript, test automatici ed export Android/iOS/web.
- Build Android release firmata con il certificato ufficiale.
- Firma, allineamento, package, versione, assenza del flag debug e checksum SHA-256.
- CI e scansione segreti GitHub sul commit della release.

## Criterio playlist

Una raccolta server viene esclusa quando nome e numero brani coincidono con un album,
oppure quando il suo contenuto comprende esattamente tutte le tracce di un solo album.
Il nome “Tekno - Sal compilation” non è inserito nel codice: resta visibile perché viene
valutato come playlist reale dai suoi metadati e dalla composizione.
