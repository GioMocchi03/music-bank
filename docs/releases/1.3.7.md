# Music Bank 1.3.7 · Android build 21

Scarica **MusicBank-1.3.7-build21.apk** dagli Assets. Richiede Android 7 / API 24+.
Installa sopra la versione precedente: **non disinstallare l'app**.
Gli archivi "Source code" sono destinati agli sviluppatori.

## Novità

- Download album e playlist, conteggio dei completati e retry dei mancanti.
- Icona download evidenziata per i brani disponibili, senza testo ripetuto.
- Offline con numero brani, spazio e filtro album/artista; copie conservate dopo logout.
- Nome autenticato, saluto secondo l'ora e banner variabile tra gli artisti più ascoltati.
- Accesso diretto al modulo server, HTTPS automatico e disconnessione esplicita.
- Rimossa la voce Media provider duplicata; controlli sui file incompleti e isolamento
  dei download di server/account diversi.

## Verifiche e limiti

Compilazione Android release e lint riusciti; TypeScript e 33 test superati; export
Android/iOS/web riusciti; UI verificata sul web con dati simulati. Firma v2/v3,
allineamento, ZIP e SHA-256 verificati. Certificato identico alla 1.3.6 build 20.

**Nessun telefono o sistema Auto era collegato per il collaudo di questa release.**
Download nativi, ascolto dopo logout e Android Auto richiedono ancora prove reali.
La coda non garantisce il completamento dopo chiusura forzata. Non viene distribuita
una build iOS. Gli aggiornamenti da GitHub sono manuali.
