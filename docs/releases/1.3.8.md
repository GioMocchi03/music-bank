# Music Bank 1.3.8 · Android build 22

Scarica **MusicBank-1.3.8-build22.apk** dagli Assets della release privata. Richiede
Android 7 / API 24 o superiore e un account GitHub autorizzato alla repository.

## Novità

- Creazione di playlist personali dalla Libreria.
- Separazione tra playlist dell'account e playlist del server/condivise.
- Rinomina, descrizione, visibilità, riordino, rimozione brani ed eliminazione.
- Controllo aggiornamenti della repository privata con token GitHub opzionale.
- Token conservato nel SecureStore Android e mai incluso nell'APK o nei collegamenti.

## Verifiche

- TypeScript, test automatici ed export Android/iOS/web.
- Build Android release firmata con il certificato ufficiale.
- Firma, allineamento, package, versione, assenza del flag debug e checksum SHA-256.
- APK pronto per l'installazione come aggiornamento della versione precedente.
- CI e scansione segreti GitHub sul commit della release.

## Limiti

- Le API Subsonic espongono proprietario e visibilità, non la cartella fisica dalla
  quale Navidrome ha importato una playlist.
- Soltanto il proprietario può modificare una playlist.
- Il controllo privato richiede un token personale con accesso `Contents: read`;
  l'app non contiene credenziali preconfigurate.
- Il browser deve essere autenticato con un account autorizzato per scaricare l'APK.
- Nessuna IPA iOS viene distribuita con questa release.
